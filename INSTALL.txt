Dynamic Island for Windows Lux — install

Recommended (installer):
  1. Run DynamicIslandLux-Setup-1.0.4.exe
  2. Finish the wizard (installs to %LOCALAPPDATA%\DynamicIslandLux\, no admin)
  3. Optional: enable “Start with Windows” in the wizard or later in Settings
  4. Tray icon appears; right-click → Settings… / Show island

Portable (no installer):
  1. Copy DynamicIslandLux.exe somewhere permanent (e.g. %LOCALAPPDATA%\DynamicIslandLux\)
  2. Double-click to run
  3. Optional: enable “Autostart with Windows” in Settings

Data (created on first launch):
  %AppData%\DynamicIslandLux\settings.json
  %AppData%\DynamicIslandLux\runtime.json
  %AppData%\DynamicIslandLux\modstorage\
  %LocalAppData%\DynamicIslandLux\logs\lux.log

Uninstall:
  - Installed build: Settings → Apps → Dynamic Island for Windows Lux, or Start Menu uninstall
  - Portable: exit from the tray, delete the exe folder
  - Optional: delete %AppData%\DynamicIslandLux\ and logs under %LocalAppData%\DynamicIslandLux\

Minimum OS: Windows 10 version 1809 (build 17763)+; Windows 11 recommended for acrylic backdrop.

Build installer from source:
  app\build.bat
  scripts\make-installer.bat
  (requires Inno Setup 6+: winget install JRSoftware.InnoSetup.7)
