Dynamic Island for Windows Lux — install

Recommended (installer):
  1. Run DynamicIslandLux-Setup-1.0.10.exe
  2. Finish the wizard (installs to %LOCALAPPDATA%\DynamicIslandLux\, no admin)
  3. Optional: enable “Start with Windows” in the wizard or later in Settings
  4. Tray icon appears; right-click → Settings… / Show island

Portable (no installer):
  1. Copy Dynamic Island Lux.exe somewhere permanent (e.g. %LOCALAPPDATA%\DynamicIslandLux\)
  2. Double-click to run
  3. Optional: enable “Start with Windows” / Autostart in Settings
     (HKCU Run: starts with --minimized — tray only until you show the island)

Data (created on first launch):
  %AppData%\DynamicIslandLux\settings.json
  %AppData%\DynamicIslandLux\runtime.json
  %AppData%\DynamicIslandLux\storage\
  %LocalAppData%\DynamicIslandLux\logs\lux.log

Uninstall:
  - Installed build: Settings → Apps → Dynamic Island for Windows Lux, or Start Menu uninstall
    (also removes the HKCU Run and StartupApproved values, including ones created from Settings)
  - Portable: exit from the tray, delete the exe folder, and delete the Run value "DynamicIslandLux" if you enabled autostart
  - Optional: delete %AppData%\DynamicIslandLux\ and %LocalAppData%\DynamicIslandLux\
    (settings, runtime, file tray, logs — the uninstaller leaves them)

Weather / lyrics / Quick Lookup contact wttr.in, lrclib.net, dictionaryapi.dev, Wikipedia, and Wiktionary.
A blank weather city lets wttr.in guess a location from your IP address.

Minimum OS: Windows 10 version 1809 (build 17763)+; Windows 11 recommended for acrylic backdrop.

Build installer from source:
  app\build.bat
  scripts\make-installer.bat
  (requires Inno Setup 6+: winget install --id JRSoftware.InnoSetup.7 -e)
  Version comes from app\CMakeLists.txt via scripts\_version.cmd
