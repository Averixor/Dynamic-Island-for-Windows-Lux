# Dynamic Island for Windows Lux

Жива пігулка поверх робочого столу Windows, натхненна Dynamic Island на iPhone. Версія **1.4.0**. Мод для [Windhawk](https://windhawk.net/): острів малюється, поки Windhawk запущений.

Ліцензія: MIT. Автор: Himanshu ([Averixor](https://github.com/Averixor)).

## Що показує

Згорнутий острів тримає час, дату і плеєр. Розгорнутий відкриває вкладки медіа, календаря, погоди й монітора системи. Окремі події тимчасово замінюють пігулку:

- відтворення: назва, виконавець, обкладинка, спектр, кнопки попередній / відтворити / наступний і смуга перемотки;
- гучність і яскравість;
- копіювання тексту або зображення;
- заряд батареї і підключення живлення;
- прогрес операції, якщо його передає інший мод;
- Caps Lock і Num Lock;
- підключення Bluetooth-пристрою;
- стан «Не турбувати»;
- сповіщення Windows (система може один раз запитати дозвіл на читання сповіщень);
- таймер фокусу.

Погода береться з [wttr.in](https://wttr.in/). Текст пісні, якщо його увімкнути з меню, запитується з [lrclib.net](https://lrclib.net/).

## Встановлення

1. Встановіть Windhawk і залиште його запущеним.
2. Відкрийте **Mods → Create new mod**.
3. Вставте вміст файлу `Dynamic Island for Windows Lux.wh.cpp`.
4. Натисніть **Compile** і увімкніть мод.

Потрібні Windows 10 або Windows 11. Мод збирається самим Windhawk, окремий компілятор ставити не треба.

## Керування

- Наведення розгортає острів. У налаштуваннях це можна змінити на клік.
- Перетягування за порожню зону пігулки переміщує острів. Зсув зберігається разом із полями **Зсув по X** і **Зсув по Y**.
- Правий клік відкриває меню.
- Повноекранне вікно ховає острів, доки його не закриють.
- **Автоприховування**: `0` ніколи не ховає, `-1` показує лише під час наведення або події, додатне число — секунди простою.

## Меню правого кліка

- Показати або сховати острів, скинути позицію, закрити мод.
- Таймер фокусу: 25 хв, 50 хв, перерва 5 хв, пауза і зупинка.
- Джерело медіа, якщо сесій кілька.
- Закріпити розгорнутим.
- Ігровий оверлей: FPS і завантаження, поки острів у спокої.
- Форма: пігулка iPhone, виліт Windows 11, виріз macOS. Виріз недоступний, якщо острів знизу.
- Розгортання наведенням або кліком.
- Текст пісні на згорнутій пігулці і у вкладці медіа. Зсув синхронізації: раніше або пізніше на 10, 50 і 250 мс, окремо для динаміків і Bluetooth.
- Прозорість: 100%, 85%, 70%, 55% або як у темі.
- Тема.
- Відкрити налаштування Windhawk.

## Налаштування

Імена нижче збігаються з підписами у Windhawk.

### Вигляд

| Параметр | За замовчуванням | Навіщо |
| --- | --- | --- |
| Позиція | Зверху по центру | Шість місць: зверху або знизу, зліва, по центру, справа |
| Масштаб розміру | 1.0 | Наприклад 1.25 або 0.85 |
| Автомасштаб DPI | увімкнено | Розмір під DPI монітора |
| Зсув по X, Зсув по Y | 0 | Додатковий зсув у пікселях |

### Поведінка

| Параметр | За замовчуванням | Навіщо |
| --- | --- | --- |
| Поверх усіх вікон | увімкнено | Острів над іншими програмами |
| Автоприховування | 0 | Секунди простою; див. вище |
| Показати при наведенні | увімкнено | Схований острів з’являється, коли курсор на його зоні |
| Розгортати при наведенні | увімкнено | Інакше острів розгортається кліком |
| Ховати в повноекранних додатках | увімкнено | |
| Перетягування мишкою | увімкнено | |

### Тема

Непрозорість пігулки: 96 (допустимо від 35 до 100). Пресети: Обсидіан, Графіт, Сланець, Nord, Вічнозелений, Еспресо, Слива, Порцеляна. Порцеляна — світла тема. Той самий список є в меню **Тема**.

**Адаптивна тема** (увімкнена) знімає колір з фону навколо острова і підганяє пігулку та текст. У меню правого кліка той самий пункт можна вимкнути.

**Ореол** — підсвітка навколо пігулки в такт басу і голосу. Варіанти: свічення, промені, кільця, орбіта. Сила ореолу: 70. Стиль також перемикається з меню **Ореол**.

### Модулі

Усі перелічені нижче увімкнені, крім секунд.

- Медіа, гучність, яскравість, буфер обміну, батарея, прогрес, Caps/Num Lock.
- Погода, календар, монітор системи (ЦП, пам’ять, відеокарта, диск, мережа).
- Bluetooth і «Не турбувати».
- Таймер фокусу.
- Годинник біля плеєра і дата біля плеєра вмикаються окремо.
- Завжди з секундами: вимкнено. Формат годинника: 24 години (`14:30`). Є 12-годинні варіанти, крапка замість двокрапки, без двокрапки і формат системи.
- Дата першою: вимкнено. Формат дати: `31.10`. Є варіанти з роком, скісною рискою, ISO і назвами місяця.

## Збірка вручну

Windhawk компілює мод сам. Якщо збирати файл окремо, потрібні бібліотеки з рядка `@compilerOptions`: `ole32`, `oleaut32`, `shcore`, `d2d1`, `dwrite`, `dwmapi`, `gdi32`, `user32`, `shell32`, `runtimeobject`, `windowscodecs`, `setupapi`, `winhttp`, `pdh`, `winmm`.
